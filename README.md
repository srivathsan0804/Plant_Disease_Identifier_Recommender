# Plant Disease Identifier & Recommender

An AI-powered web application that identifies plant diseases from leaf images using a Convolutional Neural Network (CNN).

## Features
- Plant disease detection using image classification
- CNN model powered by PyTorch
- Flask-based web application
- Disease information and recommendations
- Supplement marketplace

## Tech Stack
- Python
- Flask
- PyTorch
- CNN
- HTML, CSS, JavaScript
- Pandas

## Run Locally
```bash
pip install -r requirements.txt
cd Plant-Disease-Detection/flask_app
python app.py
